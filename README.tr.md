# Dilim

Dosyalarını bilgisayarında dönüştüren, açık kaynaklı Windows uygulaması.

[İndir](https://github.com/h-skycloud/dilim/releases) · [Kısa rehber](docs/DILIM-REHBER.md) · [Kaynak kodu](https://github.com/h-skycloud/dilim)

1. Kurulumu çalıştır; video için FFmpeg, arşivler için 7-Zip motorunu seç.
2. Gezgin'de dosya seç → **Ctrl + Alt + Boşluk**.
3. İstediğin dilime tıkla. **Tab** diğer yüz, **Esc** kapatır.

**Ctrl + Alt + T** araçları, **Ctrl + Alt + A** dosya işlemlerini açar. FileConverter ön ayarlarını Önayarlar bölümündeki XML içe aktar düğmesiyle taşıyabilirsin. Bütün uyumlu ön ayarlar ana ekrandaki listeden çalıştırılabilir.

Fotoğraf/PDF/video/ses dönüştürme ve sıkıştırma, düzenlenebilir pie menüleri, işlem kuyruğu ve geçmiş bulunur. İşlemler yereldir; dosyalar sunucuya yüklenmez. Yeni kurulumda motor indirmek için internet gerekir.

Ayarlar: `%APPDATA%/Dilim`. Kaynak ve lisanslar: [README](README.md), [LICENSE](LICENSE), [OPEN-SOURCE.md](OPEN-SOURCE.md). Filee'nin MIT temeli ve özgün atıfları korunur.
